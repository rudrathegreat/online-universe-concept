# Orbital

A Three.js solar system explorer. Serve this directory with a local HTTP server, for example `npx serve .`, and open the displayed URL. An internet connection is required for Three.js, fonts, and planetary textures.

Select Solar System from the home screen. Drag to orbit the current destination, scroll to zoom, and use 0–9 to visit the Sun through Pluto. The nine planetary orbits use mean Sun distances in AU and circular paths; their relative distances are to scale. Planet and Sun sizes are enlarged for visibility. The orbital animation is illustrative, not an ephemeris. Pluto is included as a dwarf planet.

Planet textures are provided by [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0), based in part on NASA imagery; Pluto currently uses a solid-color placeholder. These are not direct NASA texture maps. NASA/JPL's [texture map archive](https://maps.jpl.nasa.gov/tmaps/) is a potential source for a future replacement.
